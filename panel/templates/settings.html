{% if endpoint_is_ip %}

Endpoint — IP-адрес. Укажите домен (например, myvpn.duckdns.org → IP этого сервера; bash cert.sh домен сделает это сам): тогда при переезде на другой сервер достаточно перевести домен на новый IP — клиентам ничего менять не придётся.

{% endif %}

Смена endpoint/порта/DNS требует обновить конфиги клиентов. MTU на сервере меняется сразу, без отключения клиентов, — этого достаточно для загрузки видео; чтобы уменьшить и пакеты от клиента, конфиг на устройстве тоже стоит обновить. Для мобильного интернета рекомендуется 1280.

Каскад: телефон подключается к входному серверу (например, в РФ), тот пересылает трафик сюда. Входной сервер настраивается скриптом cascade/entry.sh из репозитория. Маршрут выбирается у каждого клиента в окне QR-кода.
